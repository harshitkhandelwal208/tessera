Tessera is a championship-caliber tournament Scrabble intelligence engine implemented in standard ISO C11 with zero external runtime dependencies. Developed as an alternative to traditional tree-search architectures (such as Maven and Quackle), Tessera completely eliminates game trees in favor of a 100% position-keyed Belief Lattice Directed Acyclic Graph (DAG).

In empirical tournament evaluation across 70 games against seven specialized engine archetypes, Tessera established an official Tournament Performance Rating (TPR) of 2016 Elo (71.4% win rate), scoring a 6–4 victory (+23.3 pts/game spread) against the commercial-grade 2150-Elo MAGPIE 2-ply realization engine.

Overview & Highlights

Unlike deterministic perfect-information games like chess or Go where minimax or Alpha-Beta pruning over trees can prune unvisited subtrees, Scrabble is an imperfect-information stochastic game with severe asymmetric information:

  • The identities of opponent tiles are unknown during deliberation.
  • Future rack refills depend on random draws from an unseen tile bag.
  • The identical board state can be reached through thousands of transposed move permutations.

Tessera addresses these characteristics by replacing game trees with a position-keyed Directed Acyclic Graph (DAG) indexed by 64-bit Zobrist hashes. Nodes maintain Gaussian distributional beliefs that are updated via prioritized Bellman backward induction.

System Architecture

3.1 Theoretical Foundations: Tree Elimination

In conventional tree searches, each path from the root creates an independent node. When multiple move orderings lead to the identical physical board, a tree search duplicates evaluation work exponentially.

Tessera organizes search as a Belief Lattice: a position-keyed Directed Acyclic Graph (DAG) $G = (V, E)$. Every board state $v \in V$ is uniquely identified by a 64-bit Zobrist hash. Edges $e = (u, v) \in E$ represent legal word plays. When two distinct paths reach the same board topology, they point to the identical vertex $v$, merging transpositions by construction.

3.2 Lexicon & Minimal DAWG Compression

Tessera compresses the entire SOWPODS 2019 lexicon (267,751 tournament words) into a minimal deterministic acyclic word graph (DAWG) containing 185,702 edges. Each edge is encoded into a compact 4-byte packed binary structure (`DawgEdge`):

uint32_t binary layout:
  • Bits 0..23 (24 bits): Child edge array index (addressing up to 16,777,216 nodes)
  • Bits 24..28 (5 bits): Letter code (0='A', ..., 25='Z')
  • Bit 29 (1 bit): End-of-word flag (1 if edge completes valid word)
  • Bit 30 (1 bit): End-of-node flag (1 if last sibling edge)

The complete dictionary occupies 742 KB on disk and is ingested in 0.0001 seconds using flat-array binary reading.

3.3 Appel-Jacobson Move Generation

Tessera implements the Appel & Jacobson (1988) move generation algorithm. Prior to row traversal, 32-bit cross-check bitmasks are precalculated for every empty square adjacent to existing tiles. If placing letter $c \in \{A..Z\}$ would form an invalid orthogonal cross-word, bit $(c - 'A')$ is cleared to 0. During recursive anchor traversal, legal placement is verified with a single bitwise AND operation:

\text{is\_legal}(c) = (\text{mask}[\text{row}][\text{col}] \ \& \ (1 \ll (c - 'A'))) \neq 0

Vertical word plays are generated using a transposed board representation, reusing identical row-traversal cache lines without duplicating traversal logic.

3.4 Dual-Accumulator Heuristic Evaluator

Move equity is evaluated by separating board positional impact from off-board rack leave potential across 8 discrete game phases based on remaining bag tiles:

\text{MoveEquity}(M) = \text{BoardAccumulator}(M) + \text{RackAccumulator}(\text{Rack} \setminus M)
  • Board Accumulator: Scores the play, computes premium square control (TW, TL, DW occupation to deny them to opponent), and penalizes opening floating vowels to open lanes.
  • Rack Leave Accumulator: Computes a $27 \times 27$ pairwise synergy matrix, recognizes championship super-leave stems (e.g. SATINE, RETINA, RETAINS up to +30.5 pts), applies non-linear penalties for duplicate consonants (`VV` -36.0, `WW` -20.0, `FF` -18.0), and optimizes sub-rack discards ($2^k$ subsets).

3.5 Deep Dual-Headed NNUE Architecture

Tessera incorporates an Efficiently Updatable Neural Network (NNUE) tailored for imperfect-information tile dynamics. The topology is $448 \to 128 \to 32 \to 2$ (Dual Head): 

Input Vector [448 Dimensions]
    │
    ▼  Linear (448 x 128) + Bias [SIMD AVX2 with Portable Fallback]
Hidden Layer 1 [128 Dimensions]
    │
    ▼  ClippedReLU: clamp(x, 0.0, 1.0)
    │
    ▼  Linear (128 x 32) + Bias [SIMD AVX2 with Portable Fallback]
Hidden Layer 2 [32 Dimensions]
    │
    ▼  ClippedReLU: clamp(x, 0.0, 1.0)
    ├─────────────────────────────────────────┐
    ▼                                         ▼
Head 1: Net Score Spread Margin           Head 2: Win Probability
Linear (32 x 1) -> Expected Points Margin Linear (32 x 1) -> Sigmoid P(Win)

Forward passes utilize 256-bit AVX2 Fused Multiply-Add instructions on x86-64, with automated scalar fallbacks for ARM64 and legacy systems. The static evaluation blends 50% hand-crafted leave tables with 50% neural network predictions.

3.6 Belief Lattice DAG Search

Nodes in the lattice maintain Gaussian distributional beliefs $\mathcal{B}(v) = (\mu_v, \sigma_v^2, N_v)$, where $\mu_v$ represents the expected net score spread margin, $\sigma_v^2$ is the empirical variance, and $N_v$ is the effective visit count. Nodes are stored in a 16,384-bucket open-addressing hash table indexed by 64-bit Zobrist hashes.

3.7 Prioritized DirtyQueue Bellman Relaxation

When leaf evaluations or simulations update a node belief, changes propagate backward to ancestor nodes using a binary max-heap prioritized queue (`DirtyQueue`):

Q(e) = \text{MoveStatic}(e) + \gamma \cdot \Delta_{\text{combined}}(e)
\mu_v = \max_{e \in \text{OutEdges}(v)} Q(e)

If $|\mu_v^{\text{new}} - \mu_v^{\text{old}}| > \epsilon$, all parent nodes are enqueued into the dirty heap. Updates ripple backward in prioritized waves until numerical equilibrium is reached.

3.8 2-Ply Realization & Relative Counterplay

Tessera simulates 2-ply realization by pairing candidate plays with immediate turn-2 rack refills sampled from unseen bag tiles, evaluating true realized mobility on the resulting board geometry:

\Delta_{\text{combined}}(e) = \text{clamp}\left( (\bar{S}_{\text{opp}} - S_{\text{opp}}(e)) + 0.65 \cdot (S_{\text{realized}}(e) - \bar{S}_{\text{realized}}), \, -12.0, \, +12.0 \right)

3.9 Persistent Bayesian Opponent Modeling

Tessera tracks unigram posterior likelihoods $P(t \in \text{OpponentRack} \mid \mathcal{H})$ for all 27 tile types across the entire match. Plays that score fewer points than available open stems cause the engine to downgrade opponent possession of power tiles (S, Z, X) and elevate stem likelihoods. Tile exchanges escalate weights for burdensome consonants (Q, V, W, J).

3.10 The Root Court Stopping Rule

Stopping deliberation is formulated as a Bayesian hypothesis test rather than a fixed time limit:

H_0: m^* = \arg\max_m Q(m) \text{ is the mathematically optimal move}

By drawing 1,000 joint posterior Gaussian samples, when $P(m^* \text{ is best}) \ge 98.0\%$, deliberation terminates immediately.

3.11 Exact Transposition Endgame Solver

When the bag is empty and the opponent holds $\le 7$ unseen tiles, Scrabble transitions into a deterministic perfect-information game. Tessera solves complete 8-ply endgames in under 1.5 milliseconds using an exact Negamax solver over a 32,768-entry Zobrist transposition table with depth-indexed static memory pools.

3.12 The Palimpsest (Online Meta-Learning)

The Palimpsest maintains conjugate Normal-Normal posterior distributions $\mathcal{N}(\mu_c, \sigma_c^2)$ over evaluation errors indexed by board topology classes, updating correction factors in closed mathematical form without requiring retraining.

Compiling & Installation

Tessera builds cleanly on standard POSIX environments (Linux, macOS) and Windows with GCC, Clang, or Zig. Zero external libraries are required. 

# 1. Clone repository
git clone https://github.com/harshitkhandelwal208/tessera.git
cd tessera

# 2. Build optimized engine
make clean
make -j$(nproc)

# 3. Run test suite
make test

# 4. Run benchmarks
./tessera bench

Distributed Testing & Training (Tessera-Test)

Tessera utilizes Tessera-Test, a distributed computing framework for continuous self-play neural network training and Sequential Probability Ratio Test (SPRT) patch regression testing across volunteer nodes.

Running the Community Worker Client

Anyone can contribute spare CPU cores to train the neural network and test candidate search/eval patches: 

# Download standalone Python 3 worker client
curl -sSL https://harshitkhandelwal208.github.io/tessera/worker.py -o worker.py

# Run self-play game generator
python3 worker.py --concurrency 4 --user "YourName"

# Run an SPRT benchmark match
python3 worker.py --mode sprt --games 70

Direct script download: worker.py (Standalone Python 3).

Contributing Guidelines

Tessera follows the development standard of modern open-source engines like Stockfish and Reckless:

  • Functional Changes: Any modification that alters move selection, evaluation weights, or neural network layers must be validated via an SPRT test (typically bounds $[0.0, 5.0]$ Elo).
  • Non-Functional Simplifications: Code cleanups and refactorings must preserve the exact same move count and bench signature on test positions and must not introduce speed regressions.
  • Clean Standard C11: No compiler warnings under -std=c11 -Wall -Wextra. Zero heap allocations on the hot path.

Read the full contributing manual at CONTRIBUTING.md.

Engine Protocol Specification

Tessera supports standard CLI modes for interactive play, autonomous evaluation, and headless protocol communication: 

./tessera play         # Interactive human vs AI terminal match
./tessera ai-vs-ai     # Autonomous self-play simulation
./tessera bench        # High-throughput movegen benchmark
./tessera test         # Subsystem verification suite
